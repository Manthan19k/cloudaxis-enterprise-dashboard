# 📖 Overview

CloudAxis is an enterprise-grade Infrastructure Monitoring and Management Platform designed to simplify the administration of modern IT environments.

Inspired by platforms such as **VMware vCenter**, **AWS Console**, **Microsoft Azure Portal**, **Datadog**, and **Grafana**, CloudAxis provides a centralized dashboard for monitoring physical servers, virtual machines, infrastructure health, system performance, alerts, and enterprise assets.

The platform is built with scalability, security, and modern UI/UX principles, making it suitable for enterprise environments and cloud infrastructure management.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Manthan19k/cloudaxis-enterprise-dashboard.git
```

Go to project folder

```bash
cd cloudaxis-enterprise-dashboard
```

Install dependencies

```bash
npm install
```

Run Development Server

```bash
npm run dev
```

Build

```bash
npm run build
```

Preview Production Build

```bash
npm run preview
```
